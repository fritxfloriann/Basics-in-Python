# Welcome to the Calculator Program.

This folder contains the most basic files dedicated to basic calculators for each of the math operations included. This file is for testing and for extremely basic use only. This is my first version of a calculator.

I will work on adding comments in each file and providing information for each piece of code. The main focus would be to educate users on `Basics-In-Python`, as I'm shifting my focus to my other repository. Thank you for your understanding.

## Where is the main program?

The main calculator program can be found in the repository, "`Python-Projects`". The program is located in the `calculator project` folder. After navigating to the folder, run the `calculator_main.py` program to start. Follow the instructions in the `README.md` that refer to the project during installation.

The main program can natively run to your computer without needing a terminal or command prompt like the ones in this folder.
